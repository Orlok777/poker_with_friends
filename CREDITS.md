# Credits

## Sounds

The card, chip and shuffle sounds in `client/public/sounds/` come from **Casino Audio** by
[Kenney](https://kenney.nl) (Kenney Vleugels), released under
[Creative Commons Zero (CC0)](https://creativecommons.org/publicdomain/zero/1.0/). Pack page:
<https://kenney.nl/assets/casino-audio>.

Only the files listed below are used. They were converted from `.ogg` to `.mp3` so they also play
on Safari for iPhone. Credit is not required by CC0, but it is given here with thanks.

| Event | File(s) |
| --- | --- |
| Card dealt (one picked at random) | `card-slide-1`, `card-slide-2`, `card-slide-3`, `card-slide-4` |
| Dealer's hole card turned over | `card-place-1` |
| Shoe reshuffled | `card-shuffle` |
| Chip or bet placed (one picked at random) | `chip-lay-1`, `chip-lay-2`, `chip-lay-3` |
| Chips paid out on a win | `chips-handle-5` |
| All-in bet (layered) | `chips-collide-4`, `chips-stack-1`, `chips-stack-6` |

The short win chime and the lose tone are generated in code with the Web Audio API and are not from
the pack.
