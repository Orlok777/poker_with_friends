# Credits

## Sounds

The card, chip and shuffle sounds in `client/public/sounds/` come from **Casino Audio** by
[Kenney](https://kenney.nl) (Kenney Vleugels), released under
[Creative Commons Zero (CC0)](https://creativecommons.org/publicdomain/zero/1.0/). Pack page:
<https://kenney.nl/assets/casino-audio>.

Only the files listed below are used. They were converted from `.ogg` to `.mp3` so they also play
on Safari for iPhone. Credit is not required by CC0, but it is given here with thanks.

| Event | File(s) |
| --- | --- |
| Hole card or board card dealt (one picked at random) | `card-slide-1`, `card-slide-2`, `card-slide-3`, `card-slide-4` |
| Hands turned face up at showdown, or a hand folded | `card-place-1` |
| New hand (fresh shuffle) | `card-shuffle` |
| Bet, call or raise (one picked at random) | `chip-lay-1`, `chip-lay-2`, `chip-lay-3` |
| Pot pushed to its winner | `chips-handle-5` |
| All in (layered) | `chips-collide-4`, `chips-stack-1`, `chips-stack-6` |

The short win chime, the lose tone and the soft knock for a check are generated in code with the Web Audio API and are not from
the pack.
